### Project Description

Samayamundu is a fun web application that helps users optimize their procrastination instead of their productivity. Users enter a task and deadline, and the application uses an LLM-powered system to analyze the situation and generate a humorous, personalized procrastination strategy.

### The Problem (that doesn't exist)

People procrastinate without any planning. Why waste time randomly when you can strategically calculate how much time you can waste before your deadline becomes terrifying?

### The Solution (that nobody asked for)

Samayamundu analyzes the user's task and deadline and uses an LLM to generate a personalized procrastination recommendation. Instead of telling users to stop procrastinating, it helps them procrastinate smarter, longer, and with confidence.

Because if you're going to procrastinate anyway, you might as well use AI to do it. 😭

### Implementation

For Software:

The application consists of a frontend and backend that work together to provide the procrastination recommendation system.

Users can enter a task and deadline, after which the system analyzes the available time and generates a humorous procrastination recommendation.

An **LLM-powered recommendation system using Google Gemini 3.8 Slash** is integrated into the application to understand the user's task, deadline, and available time and generate contextual, personalized, and entertaining procrastination strategies.

Supabase Authentication is used to securely handle user registration and login.

The frontend provides the user interface, while the backend handles the application logic, API communication, and interaction with the LLM-powered recommendation system.
